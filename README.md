# Welcome to the Parsons Community

This repository is for tracking issues and work related to [Parsons](https://github.com/move-coop/parsons/) that don't fit in the main Parsons repository.

We manage the tasks in this [GitHub Project](https://github.com/orgs/move-coop/projects/6).

More guidance will be added to this readme soon but in the meantime, feel free to open new issues, leave comments on issues, or ask for guidance around this repository by posting in #Getting-Help in the Parsons Slack.

You can learn more about Parsons at the [Parsons website](https://www.parsonsproject.org/).

## Adding Issues

Anyone should feel free to add new issues! We hope to create issue templates soon to make adding issues easy, but for now just put as much as you think is relevant into the new issue. If we have any questions, we will comment asking you for more info during the triage process.

Kinds of things you might make issues for include:

* an idea you have for a Parsons Party or other event
* a Parsons blog post you'd love to read and/or write
* a project idea (remember, the Parsons community includes more than just our Python package - non-Python and non-coding projects are welcome!)
* a pain point or potential improvement for our processes (ie "It's hard figuring out how to get involved" or "What if we renamed Contributor Meetings to Community Meetings?")
* wild ideas about how to improve progressive tech as a whole
* literally anything, worst case scenario is we just close your issue because it's out of scope :)

## Triaging Issues

We will triage these issues as part of our monthly (well, every-four-weekly) meetings. The triage process involves discussing the issues as needed, labeling them, and making sure they get added to our [kanban board](https://github.com/orgs/move-coop/projects/6), typically as "todo" (something we're going to get right on) or "backlog". 

## Milestones

We don't have any milestones yet but are open to creating them. Let us know if you have an idea for one!
